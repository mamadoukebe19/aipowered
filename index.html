What is CI/CD?

🔄

Continuous Integration

Every code push triggers an automated build and test process, catching bugs early before they reach production.

🚢

Continuous Deployment

Verified code is automatically deployed to your server — in this case, an Amazon EC2 Ubuntu instance.

🛡️

Reliability

Automated pipelines reduce human error and ensure every deployment follows the exact same process.

The Pipeline Steps

From git push to live server in seconds

  1. 1

    Developer pushes to main

    A git push origin main triggers the GitHub Actions workflow automatically.

  2. 2

    GitHub Actions runner starts

    GitHub spins up a fresh Ubuntu runner and checks out the repository code.

  3. 3

    SSH into EC2

    The runner uses a stored SSH private key secret to connect securely to the EC2 instance.

  4. 4

    Pull latest code

    On the EC2 server, git pulls the latest changes from the repository.

  5. 5

    Nginx serves the app

    Nginx is already configured to serve the files. The new version goes live instantly.
